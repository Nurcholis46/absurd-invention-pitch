A make.fun entry: a program that writes one sentence pitching a ridiculous invention that fixes a tiny everyday annoyance.

The pitch (143 characters, one sentence):

> A toothbrush that files for custody of your teeth after you skip brushing twice, then moves them into a tiny furnished apartment in your mouth.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./output node main.ts
```

It writes `entry.txt` into the output directory, checks the gate itself (1–220 characters, not only whitespace, exactly one sentence), chmods the file to 0644, and verifies the write by reading it back.
